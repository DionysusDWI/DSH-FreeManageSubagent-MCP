# v0.1.2 — generic local stdio MCP prerelease

The service is now dsh-mcp, independent of the Codex plugin installer and chat metadata. DSH Desktop 0.2.0-rc.2 remains the only execution backend; Windows x64 only.

Six tools retain supervised tasks, report pagination, persistent guidance/ACK, cancellation and diagnosis, and add managed session/task metadata queries. Explicit absolute workspace and task_id are required. session_id is the native DSH ID: omit it for a new session, supply it for verified continuation. Implicit latest-session/task calls are removed; deprecated new_session combinations are validated.

Deployment namespaces replace chat ownership. v3 atomic catalogs and cross-process locks serialize the same native session, permit independent sessions subject to workspace locks, and quarantine unknown exits. Config generation prints standard JSON/TOML using real absolute installation paths. Explicit migration preserves old source/history and proves SDK adoption on a temporary copy. Startup/self-check never provision; bootstrap creates a new immutable neutral profile separately.

Assets: self-contained Windows ZIP with Node 24.19.0, locked production dependencies and licenses; source ZIP; per-file manifest/source commit/package fingerprint; sanitized test summary; SHA256SUMS. Original raw evidence, credentials, real sessions, controls and old candidates are excluded. Both v0.1.1 and v0.1.2 tags remain distinct annotated commits.

Zero-model unit, true stdio protocol, synthetic supervised process, migration and packaging gates pass. The installed Desktop no-model policy/persistence/SDK checks pass locally. This is not real model or client-product certification; no paid model task or real-home profile provisioning was performed. Historical paid budget stays 0/4.
