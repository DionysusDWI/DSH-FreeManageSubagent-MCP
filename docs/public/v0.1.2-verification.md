# v0.1.2 verification scope

The historical v0.1.1 baseline passed all 270 tests, package validation, guardian and installed DSH 0.2.0-rc.2 isolated no-model API checks before its own source commit/tag. The generic suite preserves report/guidance, permission ceiling, supervisor/EOF, locks, persistence and fault coverage and replaces client-identity assertions with explicit session/namespace assertions. Test count need not equal the old client-specific suite.

The current no-model suite covers genuine stdio initialize, tool enumeration, health and sessions with non-Codex SDK clients and reconnects; synthetic backend tests cover explicit IDs, null-before-observation, same-session serialization and different-session concurrency across real MCP processes. It also covers namespace refusal, corruption/path drift, 64 KiB output, report draining, guidance durable queueing/ACK logic, cancellation/deadline, EOF and process crash quarantine. Migration dry-run/apply/source preservation/conflicts and output-only config/legacy alias conflicts are verified.

Installed-Desktop checks use a temporary home, real policy/persistence APIs and a temporary-copy native-session SDK read. No real plugin installer, runProfile or model API is invoked. Public Windows CI does not assume Desktop is installed; it tests the generic protocol and synthetic processes, with paid smoke excluded. The test-summary.json asset records exact passing test count and source commit.

Unverified: paid model behavior and costs, each particular harness product (including CC Switch/Codex installation routing), real historical-user migration, real paid child agents, full-access, complete real-agent workspace-lock matrix, frontend cancellation and large real report loads. Non-Windows execution is not release-qualified. The historical four-attempt ledger remains 0/4; new paid acceptance requires separate authorization bound to this new candidate.
