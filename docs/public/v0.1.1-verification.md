# v0.1.1 verification

The release preserves the existing runtime and five public tool schemas. Only public packaging, source filtering, release automation and sanitized documentation change.

The zero-model baseline consists of 270 tests. Packaging and guardian checks must pass. The local DSH Desktop 0.2.0-rc.2 contract probe uses an isolated temporary home and no model API. Public CI may explicitly report that installed-Desktop probe as unavailable. Detailed host identities, paths, logs, controls and sessions are retained locally rather than published.

Real paid acceptance remains 0/4; this summary is not a claim of four successful model scenarios. Test counts and results are recorded by the release build in test-summary.json.
